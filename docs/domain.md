# 排水业务约定

服务面向污水处理厂、泵站和地下管网的运行人员。时间字段统一使用带时区的 ISO 8601 字符串，事件和测量记录应保留来源时间与接收时间，不能用展示层文字替代结构化状态。

健康接口只表示进程存活，不代表任何排水业务已经完成。需要落盘的数据应使用运行时配置指定的位置，测试不得依赖主机上的隐藏状态。

## 内窥影像索引补充约定（影像采集索引服务）

1. 分段文件以 `(检测任务 id, 分段序号)` 为业务幂等键；重复上传同校验和直接命中旧行，
   同序号不同校验和必须生成 `checksum_conflict` 复核项，禁止覆盖或静默当作新片。
2. 编码器里程必须通过某个**校准版本**（轮径、每圈脉冲数）换算；替换校准参数只能
   追加新版本（`supersedes` 指向上一版），历史定位结果与报告引用不得被改写。
3. 分段序号缺口、相邻里程区间不连续或重叠，一律产生阻断性复核项；冲突之后的坐标为
   推算值（provisional），未经人工处理不得进入对外发布。
4. 复核有人工结论后（接受/驳回）坐标即视为稳定；补片后重算使旧冲突不复现时，
   系统可自动关闭对应复核项并留痕。
5. 报告发布时对缺陷坐标、换算过程、校准版本做快照；已发布缺陷状态为 `frozen`，
   新校准版本下的换算结果只能作为投影参考返回。
6. 原始影像仅项目工程师可见；调度、监管、只读角色只能访问脱敏截图与已发布内容。
7. 合并为长任务：必须支持暂停后从断点继续、失败原因持久可见、重启后队列可恢复；
   崩溃时停留在 `running` 的任务重启后按 `paused` 处理，禁止丢任务或自动判成功。
